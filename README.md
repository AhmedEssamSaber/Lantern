# Lantern

A simple command-line task tracker built with Python. Lantern helps users manage tasks and export task lists to CSV.

## Installation

Clone the repository:

```bash
git clone https://github.com/AhmedEssamSaber/Lantern.git
cd Lantern
```

No external dependencies are required. Python 3 is needed.

## Usage

Run the application using Python:

```bash
python lantern.py list
```

## Available Commands

- `python lantern.py add` - Add a new task.
- `python lantern.py list` - Display all tasks.
- `python lantern.py list --done` - Display completed tasks only.
- `python lantern.py list --sort` - Sort tasks alphabetically by title.
- `python lantern.py export --csv` - Export tasks to CSV.
